Приложение может сгенерировать ответ само, без `aiChat`. Для этого добавить сообщение пользователя, добавить пустое сообщение ассистента, перевести список в `GENERATING`, дописывать ответ по мере поступления и вернуть список в `IDLE`.

`addItem`, `appendText` и `setState` нужно вызывать в UI-потоке. В этом примере ответ готовится в `BackgroundTask`, а дописывается в `progress`, который Jmix выполняет в UI-потоке.

Пока ответ пуст, список показывает анимированный индикатор с подписью рядом. Подпись задаёт элемент `thinkingStages`: каждая стадия указывает задержку, после которой её текст заменяет предыдущий.

Лента состояний показывает, что делает ассистент, по строке на шаг. Спиннер у строки превращается в галочку, когда шаг завершён. Эти вызовы безопасны из фонового потока, а лента очищается, когда ответ готов.

`setState(ERROR)` показывает баннер с кнопкой *Retry*. Нажатие приложение обрабатывает слушателем повтора.
