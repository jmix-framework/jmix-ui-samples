В этом примере логическая группа собирается в Java через `filterComponentBuilder().groupFilter()`.

Два условия по свойствам объединяются в группу `OR` методом `addAll(...)`, поэтому клиент попадает в выборку, если имя содержит первое значение *или* фамилия содержит второе. Метод `operation(...)` переключает группу между `AND` и `OR`.
