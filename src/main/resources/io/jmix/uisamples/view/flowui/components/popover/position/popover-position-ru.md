Атрибут `position` задаёт, где всплывающая панель открывается относительно целевого компонента: над ним (`TOP_*`), под ним (`BOTTOM_*`), перед ним (`START_*`) или после него (`END_*`). По умолчанию используется `BOTTOM`. Если места не хватает, панель переносится на противоположную сторону.

Два варианта темы меняют внешний вид панели. Они задаются атрибутом `themeNames`:

- `arrow` добавляет стрелку, указывающую на целевой компонент;
- `no-padding` убирает внутренние отступы вокруг содержимого, что удобно для списков и изображений.

Щёлкните по целевому компоненту, чтобы открыть панель, а затем меняйте настройки. Панель не закрывается при щелчке вне неё, потому что атрибут `closeOnOutsideClick` имеет значение `false`.
