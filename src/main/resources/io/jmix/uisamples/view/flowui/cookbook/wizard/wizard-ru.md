Пример показывает мастер — диалог, который проводит пользователя через ввод данных по шагам. Мастер создаёт сущность `Employee` (см. `Employee.java`) и состоит из трёх шагов:

- основная информация о сотруднике;
- адрес;
- проверка введённых данных.

Каждый шаг — это `fragment`. Фрагменты объявляют контейнеры данных экрана `WizardDialog` с `provided="true"` и привязывают к ним компоненты в XML, поэтому все шаги работают с одним экземпляром `Employee`. Поля первых двух шагов проверяются перед переходом к следующему шагу. Кнопки **Back** и **Next** переключают шаги, а клик по пройденному шагу возвращает к нему.

Мастер построен на компоненте `tabSheet`, каждый шаг — отдельная вкладка. `WizardDialog` включает вкладки текущего и пройденных шагов и выключает следующие. По этому состоянию `wizard-dialog.css` превращает вкладки в индикатор шагов: выбранная вкладка — текущий шаг, остальные включённые — пройденные. Стили скрывают фон вкладок, соединяют шаги линиями и выделяют пройденные и текущий шаги акцентным цветом.
