Несколько серий `boxplot` на одной оси категорий располагаются рядом, поэтому распределения внутри каждой категории легко сравнить. Здесь каждая серия — сезон, а каждая категория — город.

Все серии читают один набор данных: в каждой строке есть по пять значений для каждого сезона, и каждая серия выбирает свои пять полей через `encode` — для оси значений и для подсказки.

Диаграмма не вычисляет статистику, поэтому это делает контроллер. Он загружает помесячные температуры сущности `TemperatureData`, группирует их по городу и сезону и вычисляет минимум, квартили, медиану и максимум каждой группы.
