Диапазонный слайдер – естественный элемент управления для фильтра. В этом примере обе границы выбранного диапазона подставляются в параметры запроса загрузчика коллекции, и таблица перезагружается при каждом изменении диапазона.

По умолчанию слайдеры работают в режиме `ON_CHANGE`, поэтому запрос выполняется в момент отпускания ползунка, а не на каждом шаге перетаскивания. Границы читаются из значения события методами `start()` и `end()`.
