Размер боковой панели `SidePanelLayout` может изменять пользователь во время работы приложения. Для этого задайте
атрибуту `sidePanelResizable` значение `true` и перетаскивайте маркер на внутренней границе панели.

Размер остаётся в пределах, заданных атрибутами `sidePanelHorizontalMinSize` / `sidePanelHorizontalMaxSize` и
`sidePanelVerticalMinSize` / `sidePanelVerticalMaxSize`.

Тема `resizer-small` отображает маркер в виде тонкой линии, ручка которой появляется при наведении курсора.

`SidePanelAfterResizeEvent` срабатывает, когда пользователь отпускает маркер, и содержит новый размер в `px`.

Выбранный размер сохраняется фасетом `settings` и восстанавливается при повторном открытии экрана.
