`aiChat` has four theme variants. Tick them above to apply them to the chat below.

`fixed-toolbar` keeps the message input controls in a row of their own at all times. Without it they share a row with the text while it fits a single line.

`input-header-component-always-visible` and `input-footer-component-always-visible` keep the `inputHeader` and `inputFooter` bands visible while the chat is empty. By default the empty state owns that space and both bands are hidden.

`no-header-footer-gap` removes the gap between the bands and the input box.

A variant set on the chat is projected onto the message input inside it.
