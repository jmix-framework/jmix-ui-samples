При фильтрации дерева каждая подходящая задача показывается под своими родительскими задачами, даже если сами родители под фильтр не подходят. Например, фильтр по умолчанию находит `Task4`, и дерево показывает её под `Task1` и `Task3`. `SimplePagination` учитывает только подходящие задачи.

Без этого решения, если фильтр исключает родителя, `TreeDataGrid` скрывает его подходящих потомков, а `SimplePagination` всё равно их учитывает.

Как это устроено:

- `genericFilter` и `simplePagination` привязаны к загрузчику `tasksDl`, поэтому в контейнере `tasksDc` только подходящие задачи текущей страницы.
- Дерево показывает контейнер `tasksTreeDc`. При изменении `tasksDc` бин `TreeAncestorsLoader` догружает из базы данных недостающих родителей, а дерево раскрывает все строки.
- Контейнер дерева сортируется штатным сортировщиком, привязанным к `tasksDl`, поэтому сортировка по колонке действует на все страницы.

`showOrphans="true"` показывает задачу на корневом уровне, если её родителя не удалось загрузить, например из-за ограничений доступа. Если родители не нужны, достаточно одного этого атрибута.
