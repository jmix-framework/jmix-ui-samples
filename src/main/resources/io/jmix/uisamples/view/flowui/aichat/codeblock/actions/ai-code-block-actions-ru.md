У блока кода есть два предопределенных действия. Копирование кладёт в буфер обмена исходный текст блока. Перенос строк переключает блок между горизонтальной прокруткой и мягким переносом.

`codeWrapped` задаёт начальное состояние переноса, как во втором блоке. Замена кода в блоке сбрасывает перенос к изначальному значению.

Любое из действий убирается атрибутом `copyActionEnabled` или `wrapActionEnabled`. Отключённое действие не отрисовывается, поэтому у третьего блока нет кнопок.

Без указания языка у блока нет строки заголовка.
