`NativeSelect` реализует `SupportsValueSource`, поэтому его можно привязать к атрибуту сущности атрибутами `dataContainer` и `property`, как стандартные поля Jmix. В примере поле привязано к атрибуту `department` сотрудника, выбранного в таблице: выберите отдел, и таблица покажет новое значение.

[`NativeSelect.setValueSource()`]({currentPath}?tab=NativeSelect.java) создаёт и активирует тот же бин `FieldValueBinding`, что и у стандартных полей, а [`NativeSelectLoader`]({currentPath}?tab=NativeSelectLoader.java) загружает атрибуты `dataContainer` и `property` через `DataLoaderSupport`. Опции из XML — строки, поэтому их можно привязать только к строковому атрибуту. Опция без атрибута `text` использует своё значение в качестве текста, а значение атрибута, которого нет среди опций, оставляет поле пустым и не меняется.

У нативного `<select>` нет режима только для чтения, поэтому, когда привязка делает поле доступным только для чтения, `NativeSelect` отключает все опции, а для обязательного атрибута — пустую опцию.
