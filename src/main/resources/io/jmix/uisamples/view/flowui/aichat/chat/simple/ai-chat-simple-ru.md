`aiChat` – готовый компонент для работы с ИИ-чатом: список сообщений, поле ввода, пустое состояние и цикл генерации, который связывает их с языковой моделью.

Для работоспособности компоненты необходим `llmProvider`, который отвечает на запрос потоком текста. Компонент отображает ответ как Markdown, превращает блоки кода в компоненты `aiCodeBlock` и показывает индикатор размышления, пока ответ пуст.

Данный пример использует не настоящую модель, а локальную заглушку, поэтому вид ответа определяется запросу. Попробуйте `code` для блока кода, `long text` для длинного ответа или `error` для неудавшейся генерации.
