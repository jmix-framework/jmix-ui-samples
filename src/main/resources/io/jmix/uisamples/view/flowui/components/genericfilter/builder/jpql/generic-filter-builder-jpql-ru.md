В этом примере JPQL-условия собираются в Java через `filterComponentBuilder()` и показаны четыре варианта `JpqlFilter`:

- `jpqlFilter()` (без аргумента) — **void**-флажок, включающий фиксированное условие `WHERE`; `defaultValue(true)` делает его активным при открытии.
- `jpqlFilter(Class)` — **типизированное** значение, привязанное к именованному параметру запроса.
- `join()` — добавляет явный `JOIN` в секцию `FROM`.
- `hasInExpression(true)` — условие `IN` по коллекции значений.
