`popoverRenderer` подходит для колонок с длинными текстовыми значениями. Он выводит значение текстом, по которому можно щёлкнуть. Если текст не помещается в ячейку, он обрезается и заканчивается многоточием. Щелчок по значению открывает всплывающую панель с полным текстом.

Атрибут `position` задаёт, где открывается панель (по умолчанию `BOTTOM_START`).
