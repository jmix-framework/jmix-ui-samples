Все доступные иконки из наборов `Vaadin`, `Lumo` и `Jmix`.

Набор `Jmix` содержит собственные иконки Jmix, которых нет в наборах Vaadin и Lumo: иконки стандартных действий, диалогов, фильтров и других компонентов. Это шрифтовые иконки из перечисления `JmixFontIcon`. В XML имя иконки без префикса, например `icon="CREATE_ACTION"`, ссылается на `JmixFontIcon`, а имя с префиксом, например `icon="vaadin:plus"`, — на набор Vaadin или Lumo. Глиф каждой иконки задаётся CSS-переменной, например `--jmix-font-icon-create-action`, поэтому иконку можно заменить в теме приложения.
