В этом примере компонент `GenericFilter` создаётся и настраивается полностью в Java с помощью builder API.

Компоненты фильтра создаются через `filter.filterComponentBuilder()`, а конфигурация собирается и регистрируется через `filter.filterConfigurationBuilder()`. Билдер выполняет всю необходимую инициализацию (делегирование условия, генерацию имени параметра и компонента значения), поэтому программно созданный компонент ведёт себя так же, как объявленный в XML.

Тот же фильтр, настроенный вручную без builder API, показан в примере [Legacy: программный GenericFilter]({contextPath}/sample/generic-filter-programmatic-legacy).
